React + Tailwind CSS. Todo App. My first React project. My skills shown in this project:

- Component architecture with lifted state and a single source of truth (callback props, no prop mutation)
- Immutable state updates with useState (functional updaters, lazy initialization from localStorage)
- useEffect for persistence, useRef for controlling native dialogs
- Controlled forms, with one modal handling both creating and editing tasks
- Full task management: add, edit, delete, complete, priority cycling
- User-created categories (add/remove) with filtering, All/Archive views and sorting by priority
- Empty states tailored to each category
- localStorage persistence (tasks and categories)
- Responsive layout: scrollable category bar on mobile, sidebar on desktop (CSS Grid)
- Accessibility (semantic HTML, native dialog, custom checkboxes and radios built on real inputs, visible keyboard focus states)
- CSS-first interactivity with Tailwind state variants (group, peer, has-checked — no JS where CSS suffices)
- Deployed to GitHub Pages
